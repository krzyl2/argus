## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | localStorage `argus-theme` key | accept | Value is only interpolated into a DOM attribute consumed by the CSS attribute selector `[data-theme="dark"]`. An arbitrary/injected value simply fails to match and falls back to light theme — no code path treats it as HTML, script, or a query. No XSS or injection surface. |
| T-10-02 | Information Disclosure | theme preference | accept | Theme choice is non-sensitive UI state; no PII. |
| T-10-SC | Tampering | npm/pip/cargo installs | accept | This plan installs no new packages; all deps already pinned in `orchestrator/ui/package.json`. No supply-chain gate applies. |

Assessment: this is a CSS-token + bootstrap plan with no new backend endpoint, no dynamic HTML
rendering, and no new dependency. Client-side attack surface is genuinely minimal.
</threat_model>
