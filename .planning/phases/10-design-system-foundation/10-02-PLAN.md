<objective>
Port the six form-control components (Button, Input, Select, Checkbox, SearchInput, Textarea)
to Preact as thin wrappers over the existing/extended `.argus-*` BEM classes. Button is the
load-bearing one (variant/size/loading API + a unit test); the input controls are near-identical
wrappers over classes that already exist in `argus.css` (from Plan 10-01). These satisfy COMP-01
for the forms category and carry the A11Y-01 focus behavior through by not suppressing it.

Purpose: Provide the shared form primitives every screen and the Wave 3 retrofit consumes.
Output: 6 new component files + 1 Button test.
</objective>
