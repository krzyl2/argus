<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| toggle → localStorage + DOM | Theme toggle writes `argus-theme` and sets `<html data-theme>` |
| route signal → active item | Sidebar reads the current hash route to highlight a nav item |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-05-01 | Tampering | localStorage `argus-theme` | accept | Written/read as one of two known strings; only ever set as a DOM attribute matched by a CSS selector. A tampered value yields light theme, no code/HTML execution path. Same disposition as T-10-01. |
| T-10-05-02 | Tampering | `location.hash` navigation | accept | Sidebar only sets `location.hash` to two hard-coded internal routes (`#/sensors`, `#/groups`); it never navigates to a caller/URL-supplied destination, so no open-redirect surface. Route parsing is the existing hardened `router.ts`. |
| T-10-05-SC | Tampering | npm installs | accept | No new dependencies (no router library added; reuse existing signal router). |

Assessment: navigation chrome + theme toggle; the only persisted state is a two-value theme
string with no injection surface.
</threat_model>
