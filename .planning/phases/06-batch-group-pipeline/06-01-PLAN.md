<objective>
Add the group config schema (GRP-01) and config-load-time group validation (GRP-04 floor + peer-mode unit guard), retiring the dead per-entity Covariates/Groups placeholders. Groups deserialize from a new top-level `groups:` key and are validated with skip-and-warn semantics that never crash the load — the foundation the scoring loop (Plan 06-04) reads per-cycle.

Purpose: Establishes the operator-facing config surface and the degrade-not-crash guard that prevents broken groups from ever reaching scoring or MQTT publish.
Output: `GroupConfig` type, `EntitiesConfig.Groups`, `ValidateGroups()`, new LogEvents, extended tests.
</objective>
