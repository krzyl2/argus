<objective>
Add the group time-alignment data source (GRP-02) and the group gRPC client methods. `GroupInfluxReader` issues one `aggregateWindow`+`pivot` query for the N×M matrix (no `fill()`, so gaps surface as null) plus one `last()`-per-member freshness query for the wall-clock staleness cap, reusing the existing `IInfluxQueryApi` seam and `_safeFluxString` injection guard. `BatchDetectorClientAdapter` gains the two Phase 5 RPC wrappers.

Purpose: Provides the correctly-aligned, gap-null, freshness-annotated data and the RPC transport that the scoring loop (Plan 06-04) consumes. Isolating this from the loop keeps the Flux/staleness design testable on its own.
Output: `IGroupInfluxDataSource`, `GroupInfluxReader`, `ScoreGroupBatchAsync`/`FitGroupAsync` on the detector client, `GroupInfluxReaderTests`.
</objective>
