## JSON contracts (AUTHORITATIVE — Wave 2 SPA types.ts MUST match exactly)

**GET /api/groups** → `{ "groups": GroupConfig[] }` where each group = `{ groupId, friendlyName, members: string[], mode, detector, params: Record<string,string> }` (ResolvedUnits is YamlIgnore'd — not serialized).

**POST /api/groups/save** body (`GroupSaveRequest`) → `{ "groups": [{ groupId, friendlyName, members: string[], mode, detector, params: Record<string,string> }] }`. Response reuses the existing `{ ok, kind, ... }` discriminant: success `{ ok:true, count }`; validation `{ ok:false, kind:"validation", errorCount }`; error `{ ok:false, kind:"error", reason }` (400 on malformed JSON).

**GET /api/detectors/catalog** → `{ "detectors": DetectorCatalogEntry[] }` where entry = `{ name, bestFor, presets: [{ label, params: Record<string,string> }], paramSchema: [{ key, type, min, max, step }] }`. Presets always exactly 3 (Low/Med/High). Include a `guided` mapping block: `{ "guided": [{ answer, detector }] }` — `"together"→"ecod"`, `"diverges"→"peer_divergence"`.

**GET /api/groups/{id}/status** → `{ "status": null }` for unknown/never-scored id, else `{ "status": { groupId, score, isAnomaly, detector, scoredAtUtc, contributions: [{ memberId, contribution }] } }`. `contributions` is empty (never null) for pca/iforest — the SPA reads empty→"no attribution".
