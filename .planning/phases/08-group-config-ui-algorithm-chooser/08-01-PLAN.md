## Param contract (AUTHORITATIVE — later plans depend on these exact key names)

Score-moving params honored after this plan. Later plans' `DetectorCatalog.cs` preset→param mapping MUST use these key names verbatim:

| Detector | Honored param keys | Effect |
|----------|--------------------|--------|
| `peer_divergence` | `threshold` (float, default 3.5) | Flag boundary `abs(z) > threshold` — fewer flags at higher threshold |
| `ecod` / `copod` | `contamination` (float, default 0.1) | Shifts `threshold_` → `is_anomaly` only; does NOT change score |
| `pca` | `contamination` (float, default 0.1) | Same as ecod/copod |
| `iforest` | `contamination` (float, default 0.1), `n_estimators` (int, default 100) | contamination → threshold only; n_estimators → score stability |

Bad/absent values fall back to defaults via the existing `_cast_float` try/except idiom (`detector/argus_detector/pyod_detector.py` lines 26-34).
