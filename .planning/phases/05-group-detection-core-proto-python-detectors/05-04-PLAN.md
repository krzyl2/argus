## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gRPC caller → ScoreGroupBatch/FitGroup | Untrusted group_id, detector name, and Series arrays cross here — the primary input-validation surface for the whole group layer |
| Servicer → ModelStore (/var/argus/models) | joblib bundle persistence via save_group_bundle; deserialization is an already-accepted local-only risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-09 | Tampering / Denial of Service | ragged Series matrix construction | mitigate | Validate all Series have identical value-array length BEFORE np.array; abort INVALID_ARGUMENT with a clear message (RESEARCH V5); asserted by a ragged-input test |
| T-05-10 | Denial of Service | very large group matrix / empty group_id | mitigate | Empty group_id aborts INVALID_ARGUMENT; body wrapped in try/except returning ok=False rather than crashing the servicer thread (mirrors existing Fit/ScoreBatch handler shape) |
| T-05-11 | Spoofing / Tampering | unknown detector name reaching the factory | mitigate | Unknown detector aborts INVALID_ARGUMENT at the handler before any model dispatch (mirrors _create_detector ValueError, surfaced as a clean gRPC status) |
| T-05-12 | Tampering | below-floor peer group producing a misleading verdict | mitigate | Below-floor returns no verdict (empty/explicit), never a false not-anomalous result (GRP-04); asserted by a floor test |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No package install in this plan (scikit-learn pin landed in Plan 05-03); no [ASSUMED]/[SUS] package added here |
