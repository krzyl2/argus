<objective>
Prime a cold streaming detector from InfluxDB history so a freshly added entity is warm from its first
live reading. Adds a `Warmup` RPC gated detector-side on `n_seen == 0`, a parametrized history query
alongside the untouched 24-hour batch query, an orchestrator call site before each `ScoreStream` opens,
and `FrozenSensorDetector` priming off the same rows.

Purpose: this is the operator's actual pain point — a newly configured sensor reporting every 30 minutes
otherwise needs roughly five days before it can raise a flag.

Output: `warmed_up` on the first live reading for entities with history, and a degrade-safe path that
never lets a missing or broken InfluxDB affect startup.
</objective>
