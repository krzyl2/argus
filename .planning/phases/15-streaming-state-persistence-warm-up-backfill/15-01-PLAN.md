<objective>
Make streaming (`hst`) detector state survive process death. Adds checkpoint save/load to
`ModelStore` outside the versioned path (D-02), a dirty-tracked periodic writer that reuses the
existing MDL-04 lock discipline (D-05/D-06), a SIGTERM flush (D-08), and a restore pass inside the
existing health gate (D-09).

Purpose: closes D1 from the ROADMAP defect table — HST model + `MinMaxScaler` + `_n_seen` are RAM-only
today, so every restart restarts a 250-reading warm-up (~5 days for a 30-minute sensor).

Output: `checkpoint.pkl` + `checkpoint.json` per `(slug, detector)`, a `CheckpointWriter` thread, and
the two `EntityDetector` accessors that plan 15-02 needs to populate the new `Verdict` fields.
</objective>
