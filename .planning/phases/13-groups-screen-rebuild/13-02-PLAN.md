<objective>
Rebuild the algorithm creation wizard to the Design System (GRP-13): restyle GuidedFlowStep's two
plain answer buttons + skip link into a DS Card with shared Buttons (copy verbatim), and swap
AdvancedParamsDisclosure's raw per-field `<input>` elements for the shared Input (external label),
all around an entirely unchanged state/groupEditor.ts chooser state machine and an already-correct
AlgorithmCard grid. The AlgorithmChooser file is touched only to add a section-label heading and to
verify (never to alter) that the catalog stays unfiltered — its draft-sync effect and radiogroup
grid are preserved byte-identical.

Purpose: D-04 requires the wizard steps (guided question → AlgorithmCard grid → SensitivityPresetPicker
→ AdvancedParamsDisclosure) to render to DS spec with radio-card 2px accent-border selection. That
selection primitive (AlgorithmCard) is already A11Y-02 compliant and string-prop-widened from Phase
12 — this plan reuses it, adding no card component and no prop change (Pitfall 3). D-03 locks the
current behavior: the full catalog shows regardless of mode and the guided step is always available;
the kit's mode-filter/joint-only gate is explicitly rejected (Pitfall 5). D-07 preserves the state
machine, SensitivityPresetPicker, and the draftParams wiring.

Output: restyled GuidedFlowStep, Input-based AdvancedParamsDisclosure param grid, a section-label on
AlgorithmChooser, two new test files, one new regression test for the preset picker, and an extended
AlgorithmChooser test guarding the no-mode-filter contract.
</objective>
