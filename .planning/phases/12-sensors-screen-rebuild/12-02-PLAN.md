<objective>
Rebuild the Sensors screen shell, list, and row to the Design System spec: DS page-header,
Card-wrapped list, Badge "tracked" pill, `groupByArea` sections (SEN-01 area/domain browse), and
the single-select-and-expand row interaction model (D-04/D-05). All business logic (state,
validation, defaults, save) stays untouched — this is a markup + local-UI-state refactor only.

Purpose: SC1 requires the list/filtering UI to match the DS spec and scale to 400+ HA entities;
D-04 replaces the current "every tracked row opens its own `<details>`" model with a single
selected+tracked row that expands inline. The `groupByArea` grouping logic (SRCH-02) already
exists and is correct — this plan flips it on and preserves the load-bearing `trackedEntityIdx`
shared-closure counter verbatim (D-08 / 12-RESEARCH.md Pitfall + Anti-Pattern).

Output: rebuilt `SensorsPage`/`SensorList`/`SensorListRow`, a new `.argus-list-row--selected` CSS
rule, and tests covering section ordering, counter uniqueness, and the select/toggle interaction.
</objective>
