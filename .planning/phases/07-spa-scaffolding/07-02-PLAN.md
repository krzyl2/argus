| Boundary | Description |
|----------|-------------|
| Supervisor Ingress proxy -> Kestrel /api/* | Nieuwierzytelniony peer LAN może próbować trafić w /api/*; auth = RemoteIp (172.30.32.2/loopback), nie nagłówek |
| SPA JSON body -> ReadFromJsonAsync | Nieufny/zmanipulowany body zapisu przekraczający walidację nie może dotrzeć na dysk ani do pipeline |
| MapFallbackToFile -> statyczne pliki | Fallback nie może serwować spoza wwwroot ani obchodzić auth dla /api/* |
