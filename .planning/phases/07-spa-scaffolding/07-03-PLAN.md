## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build-time (npm registry) -> obraz | npm ci sciaga zaleznosci w czasie build — deterministycznie przez package-lock.json |
| build stages -> runtime image | Narzedzia build (Node, SDK) nie moga wyciekac do runtime (powierzchnia ataku + rozmiar) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-08 | Tampering | npm ci w Docker | mitigate | package-lock.json zacommitowany (07-01) — deterministyczna instalacja; pakiety cleared w RESEARCH Package Legitimacy Audit |
| T-07-09 | Elevation of Privilege / attack surface | runtime image | mitigate | Node/npm/SDK tylko w odrzucanych stage ui-build/dotnet-build; runtime = aspnetcore runtime + statyczne assety; zweryfikowane przez brak COPY narzedzi build do stage 3 |
| T-07-SC | Tampering | npm/pip installs | mitigate | Brak nowych pakietow poza zatwierdzonymi w RESEARCH; asercja index.html/assets zamiast htmx zapobiega cichej wysylce zepsutego UI (Pitfall 4) |
</threat_model>
