<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Ingress client → orchestrator HTTP | Any request reaching `/api/settings` over the Supervisor Ingress prefix; untrusted until IsAuthorizedRequest confirms loopback or Supervisor IP |
| ConnectionSettings (in-process secrets) → JSON response | Secret material (tokens, passwords, TLS keys) must not cross into the serialized response |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Information Disclosure | GET /api/settings response body | mitigate | SettingsProjection builds the response field-by-field from an allowlist of 6 non-sensitive fields; never serializes the whole ConnectionSettings. Enforced by SettingsEndpointTests (no sentinel secret value, no token/password/secret/key property name in the JSON). |
| T-11-02 | Elevation of Privilege / unauthorized read | GET /api/settings handler | mitigate | Handler calls IsAuthorizedRequest(req.HttpContext) first and returns 403 otherwise — identical guard to every other /api/* route (Program.cs). |
| T-11-03 | Information Disclosure | logLevel source | accept | logLevel reads IConfiguration["Logging:LogLevel:Default"] — a non-sensitive ASP.NET log verbosity level, not a secret; null when unset. |
</threat_model>
