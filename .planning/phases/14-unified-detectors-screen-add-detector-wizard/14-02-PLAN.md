editor (D-05/D-08a), and the thin `AddDetectorWizard` hand-off (D-06/D-07). The wizard owns only sensor

save-safety guarantee (Pitfall 1, CRITICAL) — backed by a real regression test (WIZ-04).

Wave 1; main.tsx (14-04) imports `AddDetectorWizard` and `SingleDetectorEditorForm` by name.

and three test files (including the CRITICAL D-07 preservation regression test).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client `entityEdits` signal → POST /api/sensors/save | The full-list-replace save writes exactly the sensors present-and-tracked in the client edit state. An incompletely-hydrated client state (not an external attacker — a self-inflicted data-loss path) can truncate `entities.yaml`. |
